# Visual hierarchy

ผู้ใช้ต้องการให้เข้าใจว่าจะทำอะไรต่อผ่านสี ขนาด และการจัดวาง โดยไม่เพิ่มลำดับเลขหรือข้อความบอกขั้นตอนบนหน้าเว็บ

- เริ่มต้น: file picker เป็นพื้นที่ใหญ่ที่สุดใน panel ใช้ขอบและพื้นสี accent, icon ใหญ่, heading ชัด ตัวเลือกแชร์/อายุอยู่ในกลุ่มรองและยังแก้ไขได้ ปุ่มส่งที่ยังใช้งานไม่ได้ใช้สี neutral
- หลังเลือกไฟล์: picker ย่อเป็นแถวเพิ่มไฟล์ รายการที่ติ๊กมีพื้นสีต่างจากรายการที่ไม่ส่ง ปุ่มส่งใหญ่และมีสี accent พร้อมสรุปจำนวน/ขนาด ตัวเลือกแชร์กับอายุรวมในกล่องเดียว
- สำเร็จ: เลื่อนผลลัพธ์เข้ามาใน viewport เน้นลิงก์รับไฟล์และปุ่มคัดลอกลิงก์ รหัสเป็นทางเลือกที่ยังแสดงอยู่ ลิงก์จัดการแยกด้วยเส้นประและน้ำหนักตัวอักษรรอง ลดความเด่นปุ่มอัปโหลดเดิม
- รับไฟล์: ช่องกรอกรหัสใหญ่และมีขอบ accent; ปุ่มค้นหาและดาวน์โหลดกว้างเต็มพื้นที่
- เอา aside HOW IT WORKS และหมายเลขนำทางออก เมนูปัจจุบันใช้สีพื้น+เส้นใต้+น้ำหนักตัวอักษรเพื่อไม่พึ่งสีเพียงอย่างเดียว
- รักษาธีม terminal, dark/light/system, sticky header, keyboard/native controls, ขนาดไฟล์และขั้นตอน owner/receiver เดิม ไม่เปลี่ยน API หรือ deploy ในงานนี้

Verification: Chrome functional suite, screenshots desktop/mobile dark/light, lint/typechecked build; local API mocks ไม่ใช่การทดสอบ provider จริง
